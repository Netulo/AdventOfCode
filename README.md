# Advent of Code

My solutions to [Advent of Code](https://adventofcode.com) — the yearly December
series of programming puzzles — in Python, C++, C and PHP.

For me AoC is a game: riddles to crack, a way to test myself and to compete with
my colleagues. That's why **every solution here is written by me** — solving it
myself is the whole point. Some are first attempts or unfinished; I keep them as
I wrote them.

Solutions are in `YEAR/Day N/<language>/`. Puzzle inputs are not included —
Advent of Code [asks not to share them](https://adventofcode.com/about); save
your own as `input.txt` in the day's folder.
